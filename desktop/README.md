# 电脑端使用

本文对应 PC 2.9.1，兼容 Android 2.8.0，无需更新手机端。下载入口见 [项目首页](../README.md)，构建和测试见 [开发说明](../docs/development.md)。

## 安装与更新

完整解压 PC 精简包，运行 `PanelDeck.Launcher.exe`。启动助手检查 x64 .NET 10 Desktop / ASP.NET Core 运行时；缺少组件时，点击“安装缺少的运行时”后才下载并请求管理员授权。安装包来自微软，经过哈希和数字签名校验；不会自动重启电脑。组件齐全后助手启动曜屏并退出。

运行环境齐全时可直接打开 `PanelDeck.exe`。程序默认启动到托盘，双击托盘图标打开控制台，也可用 `PanelDeck.exe --show` 打开。关闭主窗口保留后台运行，完整退出使用托盘菜单。

更新前从托盘退出旧版，再使用完整的新发行目录；不要把旧自包含包的运行时文件混入精简包。PC 设置保存在 `%LOCALAPPDATA%/PanelDeck/settings.json`，更换发行目录不会删除配对。完整退出会结束采集进程。已开启自动完整采集时，日常重启自动恢复；升级采集文件后需要重新保存自动采集设置，以一次 UAC 更新受保护的副本。

## 局域网配对

1. 手机与电脑接入同一可信局域网。电脑可以有线连接，手机使用 Wi-Fi。
2. 在 PC“设置 → 连接与配对”点击“允许局域网连接…”。这次管理员授权用于防火墙配置，与硬件读取授权分开。
3. 选择手机可访问的电脑地址。VMware、VPN 等虚拟网卡地址通常不是目标地址。
4. 点击“生成配对码”，在手机设置中输入电脑地址和 8 位码，完成配对并保存。

配对码 5 分钟内单次有效，关闭 PC 设置页即失效。后续使用手机本地令牌自动连接。电脑地址或端口改变时需更新手机连接设置；建议在路由器中固定电脑的 DHCP 地址。可在 PC 设置撤销已配对手机。

防火墙规则仅允许指定发行目录的程序在 Windows 专用网络接受本地子网访问。移动程序或更改端口后需重新配置。也可在发行目录的管理员 PowerShell 中运行 `./Configure-LAN.ps1 -Port 8080`；移除规则使用 `./Configure-LAN.ps1 -Remove`。

## 登录后自动完整采集

在“设置 → 采集与运行 → 启动与后台”勾选“登录后自动完整采集”，保存并确认一次 UAC。此设置要求当前登录账户本身为 Windows 管理员；不支持标准用户借用其他管理员凭据配置自动采集，标准用户仍可使用本次手动授权。

开启后会同时启用普通权限的“登录 Windows 后启动”。主程序在登录或手动启动时调用预先授权的计划任务，只启动完整采集子进程；窗口和局域网服务不提升权限。不是登录前的系统服务，也不安装驱动。采集仍按需进行，游戏 FPS 仅在手机在线、面板亮屏时读取。

取消首次授权时，开关、登录启动和已保存设置恢复原状。关闭开关并保存时需再次确认 UAC，移除对应计划任务、结束自动采集进程；普通登录启动保留，可单独关闭。已安装的驱动不卸载，受保护的采集文件保留，不再自动运行。

任务名为 `PanelDeck.AutoCollector.<用户 SID>`，仅允许当前用户读取 / 运行，不允许普通权限修改执行内容。采集文件复制到 `%ProgramFiles%/PanelDeck Auto Collector/<用户 SID>/<安装标识>/`，只能由管理员修改。每次安装使用新目录，避免覆盖运行中的 DLL。

更新程序、任务被删除或文件损坏后会回退基础采集并提示待修复，不会在启动时弹 UAC。保留开关并重新保存设置，可主动授权修复；仍可使用主界面“授权完整读取（UAC）”。升级后的文件需重新确认一次，日常登录无需重复确认。

## 完整读取与游戏帧率

点击主界面“授权完整读取（UAC）”，同意 Windows 弹窗。主界面与局域网服务保持普通权限，同一个 EXE 启动临时授权采集进程；该进程只提供本机只读传感器管道，不监听网络。取消授权继续基础采集。关闭窗口到托盘保留授权，完整退出后结束，不注册常驻服务。

- 基础模式可以读取 CPU 使用率、内存、网速及显卡支持的指标。
- 授权后可采集全屏显示 FPS，以及需要权限的 CPU 温度、功耗和主板风扇。部分硬件指标需要 PawnIO；授权按钮不会自动安装驱动，缺失或不支持的读数显示 `—`。
- FPS 不需要 PawnIO，也不需要安装 PresentMon 或 RTSS。识别前台独占 / 无边框全屏窗口，不使用游戏名单；普通最大化窗口不算全屏，也不能仅凭窗口排除其他全屏程序。
- 手机在线且面板亮屏时才采集帧率；退出全屏、息屏或断连后暂停。可在“采集与运行”关闭该功能。

| 手机读数 | 统计口径 |
| --- | --- |
| 显示 FPS | 约 2 秒窗口内的新显示帧频率，包含可追踪生成帧，排除丢弃与重复显示 |
| 帧时间 | 同一窗口的平均显示帧间隔，单位 ms |
| 1% Low · 30s | 最近 30 秒最慢 1% 显示帧间隔的平均耗时换算 FPS；需完整窗口且至少 100 个间隔 |

三个读数来自同一活跃交换链。预热、权限不足、采集异常或数据过期时显示 `—`；目标切换或显示中断后重新统计。不会用提交 FPS 兜底，也不能保证和其他软件不同窗口、不同数据源的读数一致。详见 [实现与边界](research/game-fps.md) 和 [实测记录](VALIDATION.md)。

## 设置与日常使用

| 入口 | 用途 |
| --- | --- |
| 连接与配对 | 地址、端口、防火墙、临时配对码与撤销手机 |
| 面板外观 | 九套主题、横竖屏预览；保存后与手机同步，预览草稿不改变手机 |
| 手机屏幕 | 屏幕联动相关设置；手机亮度由手机系统管理 |
| 采集与运行 | 采样、FPS 开关、CPU 风扇接口、自动完整采集、登录启动、启动到托盘 |
| 运行环境 | 查看运行时、发行模式及打开安装助手 |
| 控制台 | 恢复自动、进入息屏、只读面板预览和导出读数 |

手机活跃连接时默认每 2 秒采样；息屏或手机未连接且控制台隐藏时放慢到每 15 秒。控制台按需创建，关闭释放界面，后台采集与连接继续运行。

网速汇总物理以太网 / Wi-Fi 的收发计数，包含局域网流量，单位为十进制 B/s、KB/s、MB/s、GB/s。首次采样、网卡变化和睡眠恢复时重建基线；未知显示 `—`，真实空闲才显示 0。风扇按稳定传感器 ID 保存，接口缺失时不会自动改选其他风扇；个别主板默认映射仍为暂定，见 [风扇说明](research/fan-mapping.md)。

电脑开机且未睡眠时手机保持显示，锁屏、静置和游戏不会触发息屏。断连等待 45 秒后息屏，恢复连接后自动显示。手动息屏持续到恢复“自动”。电脑端必须随登录运行，Windows 尚未登录时仅有采集服务不能联动手机。手机权限和省电设置见 [手机说明](../docs/android.md)。

## 常见问题与可选配置

- **更新后仍是旧版**：旧程序可能仍在托盘，单实例保护会打开旧进程。先完整退出再启动新目录。
- **游戏 FPS 为 `—`**：确认已自动或手动授权、手机在线且亮屏、目标处于前台全屏，等待采样窗口建立。游戏或驱动事件不支持时仍可能无数据；1% Low 至少需等待 30 秒。
- **温度或风扇缺失**：先检查权限和 PawnIO，再确认硬件支持。授权不会让未连接或不支持的传感器产生数据。
- **依赖旧式窗口钩子的工具不工作**：曜屏默认在自身进程禁用旧式扩展点，减少全局钩子干扰。如确有需要，可设置进程环境变量 `PANELDECK_ALLOW_LEGACY_HOOKS=1` 后重启曜屏。

旧配置可选用 `./Install-Collector.ps1` 安装 `PanelDeckCollector` 硬件采集服务，文件放入 `%ProgramFiles%/PanelDeck Collector`，以 LocalSystem 通过本机管道提供读数。仅在 PawnIO 缺失且包内有通过签名校验的安装程序时安装驱动。**服务不替代 FPS 所需的完整采集进程**；日常使用推荐自动完整采集或主界面的本次授权。

移除服务使用 `./Install-Collector.ps1 -Uninstall`，不会卸载可能被其他软件共用的 PawnIO，也不会删除受保护的安装目录。

## 数据边界

HTTP/SSE 仅用于可信私有局域网，配对码和令牌不提供加密。不要开放公网或做端口转发。传感器接口与恢复显示请求需要令牌，PC 浏览器只读预览仅允许回环地址。无云端账户或上传。

令牌保存在 PC 设置文件和 APK 私有设置中，请勿分享配置。导出硬件读数不包含令牌。采集只读取监控数据，不提供风扇曲线、频率或电压调节。
